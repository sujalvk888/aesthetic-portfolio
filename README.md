## ✧ Overview

This project is a beautifully crafted digital garden serving as the personal portfolio of **Sujal V Kanchan**, a UI/UX and Web Designer. 

The aesthetic blends dark-mode elegance with natural, botanical elements, resulting in a premium, layered user experience. From smooth gradients to deliberate micro-interactions, every detail is engineered to leave a stunning first impression.

---

## ✧ Key Features

- **Premium Aesthetics:** A sleek, dark theme paired with sophisticated typography combinations (Serif and Sans-Serif).
- **Layered Visual Depth:** Custom floral accents intersecting with the interface to create a dynamic, layered "magazine-style" feel.
- **Responsive Layouts:** Fluid, flexible designs that adapt flawlessly from large desktop screens to mobile devices.
- **Optimized Performance:** Built with Vite and React for lightning-fast loading speeds and smooth interactions.

---

## ✧ Tech Stack

- **Core:** React, Vite
- **Styling:** Vanilla CSS (Modular, highly customized tokens for complete control)
- **Typography:** Custom Google Fonts (Playfair Display, BIZ UDMincho, Inter)
- **Deployment:** Vercel

## ✧ Local Setup

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/sujalvk888/aesthetic-portfolio.git
   ```

2. **Navigate into the directory**
   ```bash
   cd aesthetic-portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```
