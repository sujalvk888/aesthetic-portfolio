## 🎨 Design & Aesthetic

This portfolio leans heavily into a **premium, editorial aesthetic**. Key visual features include:

- **Deep Burgundy & Dark Theme:** A visually striking dark mode with khaki-beige typography.
- **Floral Accents:** Custom layered PNG overlays providing an artistic, organic touch.
- **Premium Typography:** Combining elegant serifs (*Playfair Display*, *Cormorant Garamond*, *BIZ UDMincho*) with clean sans-serifs (*Inter*).
- **Smooth Layering:** Z-index hierarchies that allow text and imagery to weave together seamlessly for a sophisticated look.

## 💻 Getting Started

To run this project locally, follow these steps:

**1. Clone the repository**
```bash
git clone https://github.com/sujalvk888/aesthetic-portfolio.git
```

**2. Navigate into the directory**
```bash
cd aesthetic-portfolio
```

**3. Install dependencies**
```bash
npm install
```

**4. Start the development server**
```bash
npm run dev
```
