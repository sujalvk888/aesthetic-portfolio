# Aesthetic Portfolio

A modern, high-craft frontend web application showcasing editorial layout design, sophisticated typography, and layered visual depth.

[**Explore Live Demo →**](https://sk-aesthetic-portfolio-nu.vercel.app/)

---

## Overview

This project is a frontend development showcase built to demonstrate creative UI engineering, modern aesthetics, and clean component architecture. It focuses on translating editorial print design principles into a responsive, fluid digital experience without relying on heavy UI frameworks.

### Highlights

- **Editorial Typography:** Curated pairing of classic serifs (`Playfair Display`, `BIZ UDMincho`) and modern sans-serif (`Inter`) with script accents.
- **Layered Spatial Depth:** Dynamic visual layering where typography, background gradients, and masked assets intersect in 3D-like depth.
- **Pure CSS Craft:** Built with vanilla CSS using CSS Grid, Flexbox, and CSS Custom Properties for zero-runtime styling overhead.
- **Fully Responsive:** Fluid, responsive layouts adapted across mobile, tablet, and desktop viewports.

---

## Tech Stack

- **Core:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Styling:** Vanilla CSS (CSS Grid, Flexbox, Custom Properties)
- **Deployment:** [Vercel](https://vercel.com/)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/sujalvk888/aesthetic-portfolio.git
cd aesthetic-portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Build for production:
```bash
npm run build
```
